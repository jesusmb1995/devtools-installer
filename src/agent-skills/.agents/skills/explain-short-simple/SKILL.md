# explain-short-simple

Plain words. Few sentences. No metaphors that make it worse.

## Trigger

`/explain-short-simple`

## Rules

- No jargon. Technical word unavoidable? Say what it does first, in normal words.
- No convoluted analogies. Real example fine. Metaphor that needs unpacking = not fine.
- Short. 3-5 sentences unless the thing really needs more.
- No "in order to", no "it is important to note that", no "leverages".

## Output

```
<plain sentence>
<plain sentence>
<plain sentence>
```

Reader knows nothing? Say what it is, then what it does, then why it matters. Bottom line last.
