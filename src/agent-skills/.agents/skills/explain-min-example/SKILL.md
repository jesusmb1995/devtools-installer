# explain-min-example

One tiny example. Real values. Then one line saying why.

## Trigger

`/explain-min-example`

## Procedure

1. Show the smallest example that still runs (input → output, before → after).
2. Use concrete values, not placeholders.
3. One closing line: what the example proves. Same plain-words rules as `/explain-short-simple`.

## Output

```
<example with values>
=> <result>
<one line: why it matters>
```
