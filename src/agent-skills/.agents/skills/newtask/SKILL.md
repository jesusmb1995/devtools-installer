# newtask

Old task stays in context. New task gets full focus. No interleaving.

## Trigger

`/newtask <what to do now>`

## Procedure

1. Park: 2-3 lines — what the old task was, where it stands. Keep it in context, change nothing (no commit, no close, unless asked).
2. Switch: focus the new task completely. Old task does not bleed in.
3. User says resume (or `/gon`)? Pick the old task back up from the parked lines.
