# just-dstack

Like `/just-dpatch`, for the whole stack.

## Trigger

`/just-dstack`

## Procedure

1. Read every patch in the stack.
2. One compact block per patch: problem it solves + why this shape over the alternatives.
3. End with the stack's through-line: what the stack as a whole achieves that no single patch does.
