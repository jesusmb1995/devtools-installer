# plan-points

Bullets. Nothing else.

## Trigger

`/plan-points`

## Procedure

1. Take the plan / task / spec.
2. One bullet per actionable step. Flat; nest only for real sub-steps.
3. Verb first, target, short reason. No "make sure to", no "ensure that".

## Output

```
- <verb> <target> — <why>
- <verb> <target> — <why>
```

Done steps → `[done]` prefix, keep them visible.
